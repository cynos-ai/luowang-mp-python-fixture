# Python 注册体验 Spec

1. 注册表单接受昵称、邮箱和至少 12 字符密码。成功时创建账号、建立会话，并在页面显示 `你好，<昵称>。`；失败时不建立会话。
2. 密码字段只保存 Argon2id PHC 哈希。登录需核对密码；删除账号后，旧 Cookie 和原凭据均不得恢复登录。
3. 当前 Run 合成账号的标识以完整 `luowang-<runId>-` 开头。受控清理接口按此前缀删除账号及级联会话，独立 GET 返回余量。只读存储观察接口仅返回本 Run 账号总数、Argon2id 数和其他格式数。
4. 清理接口默认关闭；启用时要求至少 32 字符的受控 Token。不得提供任意用户 ID、SQL 或跨 Run 的清理参数。

验收需要浏览器页面、实际注册/登录/删除、真实 SQLite 聚合观察和清理回执。源码检查或单元测试不能代替运行结果。
