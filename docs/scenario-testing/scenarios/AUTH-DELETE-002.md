## 目的

未登录的客户端调用删除账号接口时被拒绝，且不删除或改变任何已有账号。

## 前置条件

- 非生产环境，仅使用合成数据。
- 存在一个以当前 Run 前缀注册的对照账号，且可提供无会话 Cookie 的客户端。

## 步骤

1. 用对照账号确认其处于可登录状态。
2. 在无会话 Cookie 的客户端调用 `DELETE /api/me`。
3. 观察响应与 `GET /api/auth/status`。
4. 再次用对照账号的原凭据登录。

## 期望

- 匿名删除请求被拒绝（非 2xx），响应不含删除成功结果。
- 匿名客户端 `GET /api/auth/status` 为未登录状态。
- 对照账号未被删除，原凭据仍能登录成功。

## 需要记录

- 匿名删除请求的响应状态与响应体错误标识（作为观察）。
- 对照账号的登录结果与账号存在性核验。
- Run 标记账号的登记、清理与清理后核验。
