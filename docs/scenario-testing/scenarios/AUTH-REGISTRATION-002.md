## 目的

使用已被注册的邮箱再次注册时请求被拒绝，不创建第二个账号、不替换会话，原账号仍可用原凭据登录。

## 前置条件

- 非生产环境，仅使用合成数据；邮箱与昵称使用当前 Run 前缀 `luowang-<runId>-`。
- 具备可发出注册与登录请求的受控能力（页面表单或等价受控请求）。

## 步骤

1. 用邮箱 `luowang-<runId>-dup@example.test` 与昵称 `luowang-<runId>-dup` 注册，确认成功并建立会话。
2. 用同一邮箱、不同昵称再次提交注册。
3. 观察第二次请求的响应与页面反馈。
4. 用该邮箱与第一次的口令调用 `POST /api/auth/login`。

## 期望

- 第二次注册被拒绝（非 2xx），页面不显示注册成功。
- 原邮箱与原口令仍能登录成功，返回的用户昵称为第一次注册的昵称。
- 重复注册后会话仍指向原账号（未被失败请求替换）。

## 需要记录

- 两次注册请求的响应状态与页面 `#message` 文本。
- 原账号登录尝试的结果；如可获得受控存储观察，记录该 Run 前缀账号数作为辅助核验。
- Run 标记账号的登记、清理与清理后核验。
