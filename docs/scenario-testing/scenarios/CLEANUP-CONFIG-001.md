## 目的

清理接口默认关闭；仅在配置了至少 32 字符的受控 Token 后才可用。

## 前置条件

- 非生产环境、可丢弃数据目录，并能在项目执行镜像中以自定义环境变量启动应用。
- 本次受控环境为已配置 Token 的运行服务，未配置或短 Token 实例的可达性待确认。

## 步骤

1. 不设置清理 Token 启动应用，请求 `GET /api/luowang/test-data/<runId>` 与其 `storage` 端点。
2. 以短于 32 字符的 Token 启动应用，观察启动与端点可用性。

## 期望

- 未配置 Token 时清理与存储端点不可用。
- Token 短于 32 字符时应用拒绝启用清理能力。

## 需要记录

- 两种配置下的启动结果与端点响应。
- 若无法构造对应实例，记录未验证原因与所需前置。
