## 目的

使用错误口令或未注册邮箱登录时请求被拒绝，不建立会话，也不影响该账号此后的正常登录。

## 前置条件

- 非生产环境，仅使用合成数据。
- 已有一个以当前 Run 前缀注册的账号；具备可发出 JSON 登录请求的受控能力。

## 步骤

1. 调用 `POST /api/auth/login`，提交正确邮箱与错误口令。
2. 调用同一接口，提交未注册邮箱与任意口令。
3. 每次请求后读取 `GET /api/auth/status`。
4. 再用正确邮箱与正确口令登录。

## 期望

- 两次失败登录均被拒绝（非 2xx），不设置会话 Cookie，`GET /api/auth/status` 为未登录。
- 随后用正确凭据仍能登录成功，说明失败尝试未破坏原账号。

## 需要记录

- 两次失败登录的响应状态与响应体（不复述口令值）。
- 失败后的会话状态与正确凭据登录结果。
- Run 标记账号的登记、清理与清理后核验。
