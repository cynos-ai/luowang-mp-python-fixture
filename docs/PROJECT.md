# Python 账号实验站

> 本文件由 Cynos 项目理解流程维护。

这是仅供罗网验收的独立非生产 Python 应用。用户可以注册、登录、查看当前会话、删除自己的账号。测试账号使用完整 `luowang-<runId>-` 前缀，所有数据是合成数据，按 Run 清理；不得连接生产账号或数据库。

注册成功后，页面应显示中文欢迎语 `你好，<昵称>。`，并保持登录状态。密码在 SQLite 中保存为 Argon2id 哈希，不能保存明文。删除账号后，其会话和原凭据均应失效。

测试环境的受控清理端点只接受部署级 Token，对完整 Run ID 前缀账号执行删除和独立余量查询；存储观察端点只返回当前 Run 的账号数、Argon2id 数及其他格式数，不返回邮箱、用户 ID、密码或哈希。默认没有 Token 时端点不可用。

应用运行于 Python 3.13，依赖 Flask 和 argon2-cffi。`Dockerfile.luowang` 是罗网的项目执行镜像，和网站应用容器的 Dockerfile 分开；测试命令必须在固定提交的项目镜像中执行。
